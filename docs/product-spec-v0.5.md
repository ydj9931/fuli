# 富丽 v0.5 产品说明

## 定位

> **富丽是宿主 Agent 之上的瞬时顾问（Transient Advisor），不是另一个常驻 Agent。**

富丽按需介入，任务结束即退出。长期留下来的应该是作品、结构、判断记录和认知资产，而不是富丽这个 Agent 状态。

## 用户心智

| 动作 | 频率 | 用户说 |
|------|------|--------|
| 安装 | 一次 | `git clone ...` |
| 扫描 | 日常 | "富丽扫描" |
| 升级 | 偶尔 | "富丽升级" |

用户不需要理解任何生命周期概念。对外只需要知道一句话：

> 富丽按需调用，任务结束即自动退出，不会长期接管你的 Agent。

## 生命周期（内部协议）

```text
用户指令
   ↓
判断是否需要富丽
   ↓
确定最小作用域
   ↓
加载富丽
   ↓
执行富丽任务
   ↓
产生结果 / 写入必要状态
   ↓
卸载富丽上下文
   ↓
恢复 Agent 默认模式
```

## 三种生命周期

| 类型 | 举例 | 生命周期 |
|------|------|----------|
| 一次性动作（默认） | 富丽扫描 / 整理 / 评审 / 发布检查 | 调用 → 执行 → 退出 |
| 项目动作 | 富丽初始化 | 建立长期项目结构 → 退出 |
| 显式持续模式 | "富丽，接下来和我一起完成这篇文章" | 富丽开始 → 多轮创作 → 富丽结束 |

持续模式必须由用户明确触发，永远不是默认。

## 完成即退出（最高优先级）

满足任一条件即退出：当前指令完成 / 当前目标对象改变 / 用户开始处理明显无关任务 / 调用其他专业 Skill / 用户显式说"富丽结束"。

## 最小作用域（三个维度）

| 维度 | 默认作用域 | 不应该默认扩大 |
|------|-----------|----------------|
| 对象 | 当前作品 / 当前创作项目 | 整个工作目录、全部工作 |
| 时间 | 当前指令 / 当前任务 | 整个 Agent 会话 |
| 能力 | 当前需要的富丽判断能力 | 持续接管 Agent 的所有操作 |

## 状态模型

只保留两个状态：`inactive` / `active(task)`。

不引入 ACTIVE / PAUSED / SUSPENDED / BACKGROUND / WATCHING / ARCHIVED 等复杂状态机。

## 与其他增益层共存

富丽（创作复利增益）与小王（项目推进增益）不是"领地划分"，而是按当前任务需要加载最小必要能力。

```text
Agent = 默认执行环境
富丽 = 创作复利增益层
小王 = 项目推进增益层
其他 Skill = 专业增益层
```

一个对象可以同时具有"工作项目属性 + 创作作品属性"，但一次操作只加载最小必要能力。

## 判断框架（不变）

L0→L6 层级、四种建议类型、最小行动原则、渐进式个性化、Native First。

v0.5 对这些判断规则没有改动。改动只在**富丽如何介入、何时退出**。

## 验收

```text
富丽扫描 → 输出建议 → 富丽自动退出 → 用户说"帮我写封邮件" → Agent 正常完成
```
