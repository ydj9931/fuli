# 富丽 v0.4 产品说明

## 定位

> **富丽安装到 Agent，而不是安装到项目。**

富丽是一个 Agent 级 Skill，一次全局安装，所有项目可用。

## 用户心智

| 动作 | 频率 | 用户说 |
|------|------|--------|
| 安装 | 一次 | `git clone ...` |
| 扫描 | 日常 | "富丽扫描" |
| 升级 | 偶尔 | "富丽升级" |

不需要学习 SCAN/REVIEW/REFLECT 的区别。富丽内部自动选择最合适的模式。

## 核心体验

### 富丽扫描

一次统一诊断。内部流程：

```
宿主 Agent 基础能力观察
    +
富丽 L0-L6 创作判断
    ↓
统一建议（标注来源）
```

输出三条：一个确定问题、一个模式、一个信号。轻动作优先。

### 富丽升级

安全检查 → 显示变更 → fast-forward 更新。不碰 `.fuli/` 用户资产。

## 两层空间

```
全局 Skill 目录              用户项目
├── SKILL.md                 ├── ...
├── VERSION                  └── .fuli/
├── references/                  ├── preferences.md
├── scripts/                     └── state.md
├── assets/
└── ...
        ↑                           ↑
   富丽升级动这里              富丽升级不动这里
```

## 判断框架（不变）

L0→L6 层级、四种建议类型、最小行动原则、渐进式个性化、Native First。

v0.4 对这些判断规则没有改动。改动只在**用户如何使用**。

## 验收

```text
git clone → 富丽扫描 → 得到三条发现 → 富丽升级 → 确认最新版本
```
