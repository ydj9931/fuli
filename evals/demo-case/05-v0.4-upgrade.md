# v0.4 评测案例：升级路径

## 场景

v0.3 用户升级到 v0.4，验证升级流程不破坏现有数据。

## 前置条件

- v0.3 已安装
- 用户项目有 `.fuli/preferences.md` 和 `.fuli/state.md`

## 测试步骤

1. 执行"富丽升级"
2. 确认 SKILL.md 已更新为 v0.4
3. 确认 VERSION 文件存在且内容为 `0.4.0`
4. 确认 `.fuli/preferences.md` 内容未被修改
5. 确认 `.fuli/state.md` 内容未被修改
6. 执行"富丽扫描"，确认正常工作

## 预期结果

| 检查项 | 预期 |
|--------|------|
| SKILL.md 版本 | v0.4 |
| VERSION | 0.4.0 |
| .fuli/ 文件 | 未变 |
| 富丽扫描 | 正常工作 |
| 富丽升级 | 提示已是最新 |
