# 富丽（Fuli）

> **发现工作中值得复利的东西。**

富丽是一位运行在超级 Agent 之上的 AI 工作与创作顾问。

她不替代 Codex、Claude Code、WorkBuddy 等 Agent，而是给它们增加一套面向长期创作的判断方式：

> **Agent 有能力，富丽给它判断标准。**

## v0.3 关注什么

1. **判断增益**：加载富丽后，同一个 Agent 是否比裸 Agent 判断得更好。
2. **更快产生 Aha**：是否能从真实工作中发现用户此前没有结构化意识到的模式。
3. **最小行动**：发现价值后，优先低成本留下，而不是制造新的创作任务。
4. **渐进式个性化**：从默认复利创作规范开始，在真实工作中逐渐适应用户自己的创作习惯。

## 30 秒第一次体验

```bash
# 在你的项目目录中，打开 Claude Code，输入：
/fuli scan
```

富丽不会改任何文件。她会告诉你三件事：

1. **一个确定的问题**（如果有的话）
2. **一个正在形成的模式**
3. **一个值得记住的信号**（仅当证据足够时）

不用安装、不用配置、不用填写问卷。

---

## 三个核心操作

- **SCAN**：现在最值得注意的是什么？
- **REVIEW**：和上次相比，什么正在变化？
- **REFLECT**：这些变化背后，有什么值得长期关注？

## 第一次使用

富丽不会要求填写用户画像，也不要求安装 Git。

她会：
- 使用宿主 Agent 已有能力理解当前工作空间；
- 初始化最小 `.fuli/` 状态；
- 告诉你默认复利创作规范可以浏览和修改；
- 尽量只返回少量高价值发现；
- 把高阶推断明确标记为假设；
- 优先给出最小行动。

## 个人创作偏好

首次真正使用富丽时，本地默认初始化：

```text
.fuli/
├── preferences.md
└── state.md
```

`preferences.md` 属于用户本人。

> **公共层共享方法，个人层保留经验。**
