# 富丽（Fuli）

> **让今天的创造，成为明天的本金。**

富丽是一套运行在你已有超级 Agent 之上的**复利创作 Skill**。

她不替代 Codex、Claude Code、WorkBuddy 等 Agent，也不要求你再维护一个复杂的“第二大脑”。

富丽做的是另一件事：

**帮助 Agent 看见你长期创造中的连续性。**

她从日常工作与创作中，发现那些值得留下的问题、作品、贡献和认知；连接过去与现在的创造；帮助一次性的工作经验逐渐沉淀为未来还能继续使用的东西。

随着时间推移，一件件零散的作品和贡献开始彼此连接，形成属于你的长期母题、认知复利和独特创作轨迹。

> **AI 越强，人越应该拥有属于自己的人生故事。**
>
> **向内复利，向外开放。**

富丽希望做的，就是让越来越强的 AI，不只是帮助你把今天的事情做完，也帮助你让过去持续参与未来。


---

## 安装

**推荐全局安装到你的 Agent Skills 目录。**

```bash
# Claude Code
git clone https://github.com/ydj9931/fuli.git ~/.claude/skills/fuli

# 其他 Agent
git clone https://github.com/ydj9931/fuli.git <Agent 全局 Skills 目录>/fuli
```

> **富丽安装到 Agent，而不是安装到项目。** 一次安装，所有项目可用。

---

## 第一次使用

打开任意工作目录，对你的 Agent 说：

```text
富丽扫描
```

富丽不会改任何文件。她会告诉你：

1. **一个确定的问题**（如果有）
2. **一个正在形成的模式**
3. **一个值得记住的信号**（仅当证据足够）

不用填写问卷，不用安装 Git，不用配置。

---

## 日常使用

```text
富丽扫描          # 看看现在有什么值得注意的
富丽升级          # 检查并更新到最新版本
```

也支持自然语言："帮我看看这个仓库""最近有什么变化？""这里有什么值得留下的？"

> 富丽按需调用，不会长期接管你的 Agent。执行"富丽扫描""富丽整理"等任务后即自动退出；只有你明确要求持续协作时，富丽才会进入多轮创作模式。

---

## 更新

```bash
# 方式一：在 Agent 中对富丽说
富丽升级

# 方式二：手动更新
cd <富丽安装目录> && git pull
```

更新只动富丽系统文件，不会触碰你任何项目的 `.fuli/` 用户数据。

---

## 卸载

```bash
rm -rf <Agent Skills 目录>/fuli
```

`.fuli/` 目录是你在每个项目里的个人数据，卸载不会自动删除。如不再需要，可以在各项目中手动删除。

## 默认复利创作规范

位于 `references/compounding-creation-guide.md`。

可阅读、可修改、可通过 GitHub 共同改进。它是默认建议，不是教条。

---

## 用户资产

富丽在每个项目中只维护最小状态：

```text
.fuli/
├── preferences.md    # 你的创作偏好（属于你）
└── state.md          # 当前工作空间理解
```

这两个文件属于你。富丽升级不会碰它们。
